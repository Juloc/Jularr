Total source artwork: approximately 801 KiB. Files are already compressed;
WebP alone does not establish optimal quality/size. Keep the originals rather
than repeatedly recompressing them. Hashed responses use immutable browser caching.

Original decoration follows the chosen accent and brightness. Real media artwork
does not. Clean uses none of this decorative framing. Controls remain opaque and
flat; no blur, animation loop or per-request image conversion is required.
