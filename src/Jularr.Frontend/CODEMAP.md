## Host and framework

- [Program.cs](Program.cs): single host, service registration, authorization, request culture and Razor/API routing.
- [UiText.cs](Framework/UiText.cs), [UiResources.cs](Localization/UiResources.cs): service-backed request language pack and English registration inputs.
- [Page.cs](Framework/Page.cs): page definitions, shared read errors and mutation redisplay.
- [Elements.cs](Framework/Elements.cs), [UiComponent.cs](Framework/UiComponent.cs): encoded HTML primitives and Razor boundary.
- [Form.cs](Framework/Components/Form.cs), [BaseField.cs](Framework/BaseField.cs): canonical Backend metadata, invariant form binding, antiforgery and field/form errors; placeholders and the label's (i) ([FieldInfo.cs](Framework/Components/FieldInfo.cs)) come from `hint.<Fields>.<Field>` texts in [UiResources.cs](Localization/UiResources.cs).
- [Table.cs](Framework/Components/Table.cs): typed rows and composed cells.
- [Button.cs](Framework/Components/Button.cs), [Tag.cs](Framework/Components/Tag.cs), [Toggle.cs](Framework/Components/Toggle.cs): shared controls.
- [Split.cs](Framework/Components/Split.cs), [Tabs.cs](Framework/Components/Tabs.cs), [NavigationTabs.cs](Framework/Components/NavigationTabs.cs): layout and route-backed navigation.
- [Shell.cs](Pages/Shared/Shell.cs), [Brand.cs](Pages/Shared/Brand.cs): capability-driven application chrome and branding; administration areas are collapsible sidebar groups.
- [Shared layout](Pages/Shared/_Layout.cshtml), [page body](Pages/Shared/_PageBody.cshtml): thin Razor bridges.
- [FrontendAssets.cs](Framework/FrontendAssets.cs), [Vite](vite.config.ts), [build tools](Tools): fingerprinted, entry-scoped assets and SVG sprite.
- [Shared SCSS](Assets/Shared/shell.entry.scss): colocated base component styles loaded once.
- [Appearance](Modules/Appearance/Appearance.cs), [palette](Modules/Appearance/Palette.ts), [theme client](Modules/Appearance/theme.entry.ts): Original/Clean, brightness and optional device preferences.
- [Original artwork](Modules/Appearance/Original/README.md), [skin styles](Modules/Appearance/Theme.scss): Washi, blossoms, landscapes and mascot; shared Hero fallback, no provider-art tinting.
- [ByteSize.cs](Framework/ByteSize.cs): file and volume sizes in decimal units for every page.
- [FactList](Framework/Components/FactList.cs): labelled numbers and states (statistics, system overview).
- [Sparkline](Framework/Components/Sparkline.cs): a server-drawn line over evenly spaced values (system performance).
- [MediaCard](Framework/Components/MediaCard.cs), [client](Framework/Components/MediaCard.ts): one portrait cover across all catalogs, bottom-edge progress, equal hover actions and optional same-height trailer. [MediaBookmark](Framework/Components/MediaBookmark.cs) uses the existing Details POST with a local return URL and antiforgery; missing membership links to Details. [Client tests](Tools/media-card.test.mjs).
- [MediaPreview](Framework/Components/MediaPreview.cs), [client](Framework/Components/MediaPreview.ts), [tests](Tools/media-preview.test.mjs): opt-in status links, inert SSR content and one native modal; official trailer embed on Play, released on close. Design examples await real trailer/request/download service fields.
- [MediaAvailability](Framework/Components/MediaAvailability.cs): dot-to-capsule status with shared vivid palette, partial counts and explicit profile/other-audio combinations. List services still lack audio completeness and trailer IDs; no Frontend inference. Eight development samples: `/Design?pane=cards`.
- [MediaLanguages](Framework/Components/MediaLanguages.cs), [IconInfo](Framework/Components/IconInfo.cs): supplied preferred flags/counts and native accessible disclosures; Design labels missing service fields.
- [MediaShelf client](Framework/Components/MediaShelf.ts): shared local chevrons, native touch/keyboard scrolling and fragment observer cleanup; [tests](Tools/media-shelf.test.mjs).
- [MediaHero](Framework/Components/MediaHero.cs), [MediaShelf](Framework/Components/MediaShelf.cs), [MediaImage](Framework/Components/MediaImage.cs): shared media presentation; Backend owns image processing.

## User and account pages

- [Discover](Pages/User/Discover/Index.cshtml.cs), [client](Pages/User/Discover/Index.entry.ts): local-first landing with Continue Watching, Listening and Reading shelves, recommendation HTML fragments, debounced search and progressive result paging.
- [Provider title](Pages/User/DiscoverItem/DiscoverItem.cshtml.cs): TMDB title and authorized request before canonical Work creation; [catalog title](Pages/User/DiscoverCatalog/DiscoverCatalog.cshtml.cs) the same for a book, light novel, manga, album or game found in its catalog, and an anime season shown as AniList shows it (a known one opens its series). The scopes of the media-type bar come from `ReadDiscoverScopesV1`; the catalog page reads its title from the catalog.
- [Library](Pages/User/Library/Library.cshtml.cs), [Watchlist](Pages/User/Watchlist/Watchlist.cshtml.cs): real bounded catalogs; both narrow by [LibraryScopes](Framework/LibraryScopes.cs) type tabs and sort.
- [Details](Pages/User/Details/Details.cshtml.cs): Work, paged versions, personal actions and capability-based Play/Read links; a series shows its seasons beside [episode cards](Framework/Components/EpisodeCard.cs) (still, length, progress, state chip).
- [Player](Pages/User/Player/Player.cshtml.cs), [chrome](Framework/Components/Player.cs), [client](Modules/Player/player.entry.ts): PlaybackPlan, transport, HLS and progress; Audio and Subtitles direct actions with their panels (another audio track asks for a new plan at the same position, subtitles are WebVTT tracks), languages through [LanguageLabel.cs](Framework/LanguageLabel.cs). Minimize keeps the same session in a bar while [Navigation.ts](Modules/Navigation/Navigation.ts) swaps the app area for same-origin app links (page scripts run again per visit; forms, reader, account and setup pages, failures and script-less browsers load normally); Expand returns to the full player, Stop ends the session. Previous and Next lead to the neighbouring unit of the same Work; the full player continues there at the end.
- [Reader](Pages/User/Reader/Reader.cshtml.cs), [client](Modules/Reader/reader.entry.ts): sanitized sections, device settings, semantic locators and end-of-content completion. [Translation](Modules/Reader/Translation/translation.ts) picks the book's language (tag, else kana/kanji or common words), uses the shared section translation or translates in [a worker](Modules/Reader/Translation/translation.worker.ts) with Mozilla's [Bergamot loader](Modules/Reader/Translation/bergamot-translator.js) (MPL-2.0, Firefox revision 2c8de06acae0 for engine 3.0; local changes: default export, `globalThis` for strict mode) and shares the result; marks pause while a translation shows. Comics use the [comic client](Modules/Reader/comic.entry.ts): one page or a spread (cover and wide pages alone), reading direction (Manga right to left), three pages preloaded, `p<page>` as locator; without script, page links.
- [Continue Reading bar](Framework/Components/ContinueReadingBar.cs), [fragment](Pages/User/ContinueReading/ContinueReading.cshtml.cs), [client](Framework/Components/ContinueReadingBar.ts), [tests](Tools/continue-reading.test.mjs): the most recent unfinished book or comic at the bottom of app pages; one Continue action and Dismiss, which hides it on this device until the position changes. Playback owns the slot while the mini player is open.
- [Game](Pages/User/Game/Game.cshtml.cs), [client](Modules/Game/game.entry.ts), [helpers](Modules/Game/Game.ts), [tests](Tools/game.test.mjs): EmulatorJS from `/emulator/` (installed by [emulator-assets.mjs](Tools/emulator-assets.mjs) during the build), the page's connections limited to Jularr; the profile's save memory replaces the browser copy at start and uploads when the emulator flushes it, save states travel gzip-compressed through the emulator's own Save/Load State, play time is reported while the game runs visibly.
- [Progress transport](Modules/Tracking/Progress.ts): serialized acknowledged writes, finite transient retries and visible unsaved state for Reader/Player.
- [Requests](Pages/User/Requests/Requests.cshtml.cs): profile queue and authorized source confirmation.
- [Statistics](Pages/User/Statistics/Statistics.cshtml.cs): the profile's numbers for 7 days, 30 days, a year or all time. [System](Pages/Admin/System/System.cshtml.cs): the Owner's overview with links to the pages that act, performance of the process and its services, recent warnings and errors.
- [Calendar](Pages/User/Calendar/Calendar.cshtml.cs): a month grid of upcoming releases with a media-type filter, or two weeks day by day as the agenda.
- [Collections](Pages/User/Collections/Collections.cshtml.cs), [one collection](Pages/User/Collection/Collection.cshtml.cs): list and creation, Works grid with name and filter editing; Details adds to and removes from hand-picked ones.
- [Notifications](Pages/User/Notifications/Notifications.cshtml.cs): the profile's inbox, mark as read and one switch per kind; the bell with its unread count sits in the [Shell](Pages/Shared/Shell.cs) header (count read once per request by `UiText`).
- [Settings](Pages/User/Settings/Settings.cshtml.cs): profile settings, home shelf order, appearance and granted administration links.
- [Login](Pages/Account/Login/Login.cshtml.cs) (links to [Register](Pages/Account/Register/Register.cshtml.cs) while the Registration module is on; the new account waits until an administrator enables it), [Profiles](Pages/Account/Profiles/Profiles.cshtml.cs), [PIN](Pages/Account/ProfilePin/ProfilePin.cshtml.cs) (numeric input that confirms itself at the PIN's length), [New profile](Pages/Account/ProfileNew/ProfileNew.cshtml.cs), [Sessions](Pages/Account/Sessions/Sessions.cshtml.cs), [Logout](Pages/Account/Logout/Logout.cshtml.cs): canonical service-driven authentication flows.
- [AccessDenied](Pages/Account/AccessDenied/AccessDenied.cshtml.cs): catalog-backed 403.
- [Setup](Pages/Setup/Start/Start.cshtml.cs), [Setup Storage](Pages/Setup/Storage/Storage.cshtml.cs), [Progress](Pages/Setup/Progress/Progress.cshtml.cs), [Finish](Pages/Setup/Finish/Finish.cshtml.cs): first Owner, resumable steps and completion. The Admin Instance, Acquisition, Providers and Takeover editors also answer under `/Setup` ([PageConventions.cs](Framework/PageConventions.cs)) inside the [SetupWizard.cs](Framework/SetupWizard.cs) frame.

## Admin pages

- [Accounts](Pages/Admin/Accounts/Accounts.cshtml.cs): roles, profile assignments and sessions.
- [Backup](Pages/Admin/Backup/Backup.cshtml.cs): backups with their schema version, back up now, delete; under `/Setup/Backup` also restore.
- [Instance](Pages/Admin/Instance/Instance.cshtml.cs): supported settings and module controls.
- [Storage](Pages/Admin/Storage/Storage.cshtml.cs): mounts with their last observed state, WOL, safe browsing and independently paged library paths.
- [Providers](Pages/Admin/Providers/Providers.cshtml.cs): registry, protected TMDB/IGDB credentials, Plex server, and with ProgressSync the Jellyfin/Emby connections and which profile each server user shares progress with.
- [DeviceLink](Pages/Account/DeviceLink/DeviceLink.cshtml.cs) (`/Devices/Link`, anonymous): a browser on a TV shows a pairing code and [QrCode](Framework/Components/QrCode.cs), kept in a strict cookie, and signs in once confirmed.
- [DevicePair](Pages/User/DevicePair/DevicePair.cshtml.cs) (`/Devices/Pair`): shows device, platform and code, then confirms it for the active profile; opening it never pairs. [DeviceNames](Framework/DeviceNames.cs) shows a device without its own name with the translated default.
- [Works](Pages/Admin/Works/Works.cshtml.cs), [Work](Pages/Admin/Work/Work.cshtml.cs) (metadata, its series and place, a wrong match replaced by another provider entry, and named unit sections; [manga volume upload](Pages/Admin/WorkUpload/WorkUpload.cshtml.cs)), [Person](Pages/User/Person/Person.cshtml.cs) (`/People/{id}`: a person's titles, linked from the details' creators, cast and crew), [Franchise](Pages/User/Franchise/Franchise.cshtml.cs) (a series' titles in their order), [AniList matches](Pages/Admin/Matches/Matches.cshtml.cs), [Library inventory](Pages/Admin/Library/Library.cshtml.cs): metadata, editing, matching, file identification, naming patterns and rename preview.
- [Admin library](Pages/Admin/Library/Library.cshtml.cs), one address per view in the sidebar's Library area: the overview of every library (titles, files, size, missing and unidentified, last scan, scan), unmatched and assigned files (`?root=` for one library) (keep only one version, protect from automatic upgrades), confirmed renames, naming patterns, and Files & versions (upgrade behaviour, several releases, recycle mode, folder and days); [subtitles of a video](Pages/Admin/Subtitles/Subtitles.cshtml.cs) searched and chosen by hand.
- [History](Pages/Admin/History/History.cshtml.cs) (`/Admin/History`, also one Work's): what happened to the media, newest first.
- [Requests](Pages/Admin/Requests/Requests.cshtml.cs), [Wanted](Pages/Admin/Wanted/Wanted.cshtml.cs) (list), one [target](Pages/Admin/WantedItem/WantedItem.cshtml.cs) per page (status with searches, profile and library, seasons and episodes each searched automatically or by hand, releases) and its [manual search](Pages/Admin/WantedSearch/WantedSearch.cshtml.cs), [Activity](Pages/Admin/Activity/Activity.cshtml.cs): moderation, acquisition and recovery; the admin Work links to its target.
- [Acquisition](Pages/Admin/Acquisition/Acquisition.cshtml.cs), [Sources](Pages/Admin/Sources/Sources.cshtml.cs), [Quality profiles](Pages/Admin/Profiles/Profiles.cshtml.cs) and one [profile](Pages/Admin/Profile/Profile.cshtml.cs) per page (sections, quality ladder, release rules edited in place): connection/catalog/profile configuration; connections have one address per role (`/Admin/Acquisition`, `/Downloads`, `/Subtitles`) and an indexer test search.
- [Takeover](Pages/Admin/Takeover/Takeover.cshtml.cs): one-time Prowlarr/Sonarr/Radarr preview and import.
- [Localization](Pages/Admin/Localization/Localization.cshtml.cs), [Languages](Pages/Admin/Languages/Languages.cshtml.cs): DB descriptions, translations and locale administration.
- [Request users](Pages/Admin/Users/Users.cshtml.cs), [Rules](Pages/Admin/Rules/Rules.cshtml.cs): rule list and editor; accounts with their resolved rule, assignment and overrides. Details offers the rule's qualities when requesting.
