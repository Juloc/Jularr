# Was das Repository nicht aufnimmt

`lab/torrent-vpn/vpn/jularr.conf` (die Anbieter-Konfiguration) und `lab/torrent-vpn/.env` (das
temporäre Passwort des Torrent-Clients) gehören nicht ins Repository.

```
lab/torrent-vpn/vpn/jularr.conf
lab/torrent-vpn/.env
lab/torrent-vpn/qbittorrent/config/
lab/torrent-vpn/qbittorrent/downloads/
```

Die Beispielform steht in `lab/torrent-vpn/vpn/jularr.conf.example`.
